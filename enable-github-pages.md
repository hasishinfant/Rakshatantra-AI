# Enable GitHub Pages Deployment

## Automatic Setup (GitHub Actions is already configured)

The GitHub Pages deployment workflow has been created and pushed. To complete the setup:

### Step 1: Enable GitHub Pages
1. Go to your repository: https://github.com/hasishinfant/Rakshatantra-AI
2. Click on **Settings** tab
3. Scroll down to **Pages** section in the left sidebar
4. Under **Source**, select **GitHub Actions**
5. Click **Save**

### Step 2: Verify Deployment
1. Go to the **Actions** tab in your repository
2. You should see the "Deploy to GitHub Pages" workflow running
3. Wait for it to complete (green checkmark)
4. Your site will be available at: **https://hasishinfant.github.io/Rakshatantra-AI/**

## Manual Verification

If the automatic deployment doesn't work, you can also:

1. Go to repository **Settings** → **Pages**
2. Set **Source** to "Deploy from a branch"
3. Select **gh-pages** branch (if it exists)
4. Click **Save**

## Troubleshooting
If the site doesn't load:
1. Check the Actions tab for any failed deployments
2. Ensure GitHub Pages is enabled in Settings
3. Wait 5-10 minutes for DNS propagation
4. Try accessing the site in an incognito window

The deployment is fully automated - any future pushes to the master branch will automatically update the live site!
